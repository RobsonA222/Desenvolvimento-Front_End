Alunos iniciam projeto de página pessoal

26 de setembro de 2026 || 10h:23min

Os estudantes da disciplina de desenvolvimento front-end iniciaram a criação da página pessoal.

O projeto utiliza titulo, parágrafos, imagens , links, menus de navegação e diferentes elementos sêmanticos.

Na proxima etapa, os estudantes aplicarão CSS para modificar o layout da página.
